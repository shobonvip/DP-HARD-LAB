# v0.5.9：ホーム習熟・皿リズムと身体動作を分けた実験モデル

現行v0.5では、周囲の配置認識・指ごとの動作頻度・判定生成をさらに変更した。[v0.5の仕様](CONTEXT_TIMING.md)を併せて参照。以下は寸法と身体動作の基礎、およびv0.4時点の記録。

対象環境はACのLIGHTNING MODEL。2026-09-27のユーザーの指摘をもとに、ホーム運指に慣れた人を標準とする。実機の完全な寸法・力学測定はなく、以下の数値を「LIGHTNING MODELの実測値」として扱わない。

## 負荷の意味

ゲージに入る需要は、身体側と認識・習熟側の和を、その手の能力比で割ったもの。

- 身体側：動作頻度、時間不足、指の重複、手の届く幅、指の交差・連動、押下力、左右協調、活動の蓄積、皿動作、CN拘束。
- 認識・習熟側：ホーム配置の読み慣れ、リズム変化、階段の習熟、桂馬の習熟、ホーム外運指への不慣れ。

二つは異なる単位の物理測定値ではなく、仮の係数で足し合わせた無次元のモデル負荷。表示する移動距離（mm）、仮定した力（N）、仕事の近似（mJ）も実プレイの測定値ではない。筋骨格の逆動力学、痛み・傷害・生理的疲労の予測は行わない。

## 運指と慣れ

右手換算のホームは `1親 / 2・3人 / 4中 / 5・6薬 / 7小`。拡張候補には親3・親5、中5・中6、小6などを含む。ホーム外を使う費用は拡張習熟度で変わる。ホームのみのモードでは候補を固定する。同指同時押しは高コストとして残り、完全な実行可能性判定ではない。

| 調整項目 | 標準値 | 意味 |
|---|---:|---|
| ホーム習熟 | 0.95 | ホームの指対応で読める配置の認識軽減 |
| 拡張運指習熟 | 0.30 | ホーム外運指を選ぶ負荷の軽減 |
| 階段習熟 | 0.25 | 連続した段階的移動を読む負荷の軽減 |
| 桂馬習熟 | 0.35 | 密集した離れた白黒配置を読む負荷の軽減 |
| 指の独立運動習熟 | 0.55 | 指の連動に対処する負荷の軽減 |

0は不慣れ、1は十分な習熟を仮定した端点。実プレイヤーの測定尺度ではない。認識が容易になっても、必要な移動距離や押下の仕事が消えるわけではない。現段階では左右の習熟値は共通、左右差は能力比で扱う。

階段は直近3回の同手単鍵が同じ向きに1～2レーンずつ進み、間隔が各0.5秒未満のもの。v0.3の「階段だから一律に認識負荷を55%削減」を廃止した。今回の桂馬検出は1–4、2–5、3–6、4–7の白黒ペアが同時、または0.16秒以内に現れる場合の近似。白黒が混在する配置をすべて桂馬とは判定しない。複合配置全体の厳密な分類ではない。

認識の学習値だけで「階段は必ず難しい」と順位を固定しない。個人の設定、テンポ、指移動、同指連続、皿との複合で結果が変わる。指の連動・交差についても本モデル独自の小さな加算を使い、特定論文からIIDX用の係数を推定したとは主張しない。

## 皿の運動

v0.5.8では、非ソフラン☆12のereter HC順位を用いた保留群比較により、合成需要へ加える皿コストを従来の約87%へ調整した。v0.5.9では皿の間隔列から局所リズム複雑度を推定する。単純で規則的な高速連皿はHARDで一部を取りこぼせる前提で動作頻度・反復・切り返しの負荷を軽くし、間隔の種類と変化が多い連皿には認識負荷を足す。複雑度は直近・直後の最大8区間の拍比を1/24拍単位へ丸め、間隔分布のエントロピー、隣接間隔の変化率、短周期反復を組み合わせる。1.25拍を超える休止とテンポ境界をまたぐ間隔は除く。係数0.35は皿負荷の12区間から抽出した360譜面のうち保留187譜面で最良だった。皿リズム上位25%の順位相関は軽減なしの0.762から0.803へ、平均絶対順位差は14.97から13.83へ改善した。標準設定では規則的な連皿の動作重みは65%まで下がり、複雑な連皿は最大の重みを保つ。係数は外部順位への限定校正で、実プレイ成功率では未校正。物理的な皿移動や鍵盤との着地負荷は引き続き評価する。

v0.5.4では、距離だけで同時皿を許していた近似に、左1/2/3＝親／人、4＝限界付近、5/6/7＝通常の同時到達不可というプレイヤー由来の制約を追加した。右は反転の仮定。無理皿のずらしと判定時刻の扱いは [打鍵時刻の仕様](CONTEXT_TIMING.md) に記載する。

鍵盤から皿へ到達する移動と、皿上で指が往復する運動を分ける。接触継続中の連皿では前者が0、後者が `接触半径 × 角度（rad）`。標準設定なら1ストローク約14.4mm。接触点は円弧の両端を交互に移動し、皿＋鍵盤では両端における届き方を評価する。

角加速度は停止→移動→停止の三角速度近似で `4θ/t²`、必要トルクは `抵抗トルク + 慣性×角加速度`、接線方向の力は `トルク/半径(m)` とする。動作時間は20～300msの範囲で仮定。力を押し／引きそれぞれの基準力と比較して負荷に加える。慣性による加減速のエネルギー回収や実測の角速度曲線は扱わない。表示の仕事は正の入力の粗い指標で、正味の力学仕事ではない。

最初の皿は押し、その後の連皿は交互。片方向に回し続ける運指や持ち替えの最適化は未実装。BSS保持中には架空の判定やストロークを増やさず、保持と終点を近似するため、長いBSSの持続的な仕事は過小評価する。

## 人間工学を参照する範囲

[Kimotoほか（2021/2022）](https://doi.org/10.1093/cercor/bhab229)はピアニストと非経験者を比較し、薬指の受動的な連動や神経筋の協調が経験で異なることを報告した。実験1は13人対12人、実験2は13人対13人。これは「生体力学と習熟を分けて検討する」設計の参考であり、IIDXの親5・中6・小6の難度や本実装の係数を裏付ける実験ではない。慣れればすべての指が一様に独立するという解釈もしない。

## 検証と次に必要な測定

合成譜面で、ホーム習熟による認識軽減、階段・桂馬習熟の独立した効果、習熟を変えても移動・仕事が残ること、円弧長、押し引きの非対称性、抵抗増による皿負荷増を検査する。連打・トリルを階段に含めないこと、皿だけの配置にホーム習熟による軽減を適用しないことも検査する。これらは実装の検査であって実プレイ精度の検証ではない。

`node scripts/ergonomics-validation.mjs` で4パターン×7設定の感度記録を `data/ergonomics-validation.json` に出力できる。異なるパターンはノーツ数が違うので、同じパターン内で設定を変えた差を見るために使う。

実機では鍵盤中心座標・皿接触位置・皿面高、各重さ設定の抵抗、押し引きの角変位と所要時間、ボタンの力–変位を測る必要がある。その後、プレイヤーごとの習熟と成功・失敗記録で係数とミス確率を校正する。

旧v0.3は `DP-HARD-LAB-v3.html` と `data/table-v3.json` に保存。新しい設定は個別再試行へ反映され、一覧の難易度は標準プロフィールでの評価に固定する。
