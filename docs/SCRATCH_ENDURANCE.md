# 連皿の持続負荷と譜面別BPMの修正

0.6.1-scratch-endurance-experimental、比較元0.6.0-motor-placement-experimental。H5とereter HCを同じ☆12集合内で百分位化。正の差はモデル側が難しい方向。

## 変更と検証

全742譜面の順位相関 0.80 → 0.82、平均絶対順位差 13.49 → 12.91。20ポイント以上の差 161 → 157譜面。

譜面別BPMで除外した非ソフラン657譜面の相関 0.82 → 0.83、順位差 12.93 → 12.38。以前の「非ソフラン」集計には曲共通BPMによる誤分類があったため、旧集計と母集団が違う。この報告の前後は同じ修正済み母集団。

係数は学習群の誤差だけで選び、保留群は選定後に確認。ereterは過去にも調整に使った母集団であり、独立した実プレイ成功率検証ではない。

- 曲共通BPMでなく、譜面のテンポイベントから範囲とソフラン有無を取得。TITANS RETURN(L)は97～194。ソフラン攻略・HS操作は未対応のまま、比較対象から正しく除外する。
- 手の動作頻度に含まれる皿の割合を追跡し、鍵盤向けの重複軽減から皿成分を保護する候補を比較。
- 皿上の移動距離を8秒の減衰履歴に累積し、持続する動作に追加負荷を与える。休憩では回復する。規則的なリズムでも実際の皿移動は消えない。8秒・基準3回/秒・上限などは仮定であり、人間の疲労の実測値ではない。
- 採用値（保護、持続負荷）: [1,2]。ソフラン認識やHCN継続判定を再現した修正ではない。

## コメントで確認した難所

- [TITANS RETURN(L)](https://w.atwiki.jp/bemani2dp/pages/3897.html)：低速、HCN絡み、三角同時押しが挙げられている。これを契機に元譜面を確認し、BPM分類の誤りを発見。
- [灼熱Pt.2(A)](https://w.atwiki.jp/bemani2dp/pages/2797.html)：長い連皿、体力、着地、24分皿への言及がある。短い指疲労だけでは持続負荷を表現できないという仮説を検証した。
- [GOBBLE(H)](https://w.atwiki.jp/bemani2dp/pages/487.html)：隣接白黒同時押し、付加ノーツ付き縦連、無理皿の取捨、BADハマりが指摘されている。単純に皿枚数を増幅すれば解決する問題とは扱わない。

コメントは個人の攻略経験で、統計的な正解ラベルではない。曲名ごとのミス率補正には使用していない。

## 改善と残る問題

灼熱2曲の過小評価は縮小した。一方、Makin' Itとdica dicaは過大評価が強まり、全体の改善がすべての皿譜面に当てはまるわけではない。規則的な連皿を省力化する動きと、複雑な皿・着地で持続する負担の区別が次の検証候補になる。これは残差からの仮説で、曲別補正は加えていない。

GOBBLEとLogic Boardの必要能力は今回変わっていない。他曲の順位上昇と☆換算の再校正によって表示値が下がるため、これを配置難の修正と解釈しない。付加ノーツ付き縦連、無理皿の取捨と立て直し、HCN継続判定などは引き続き検証が必要。
