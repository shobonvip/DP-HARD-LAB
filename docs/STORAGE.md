# 容量の軽量化（2026-10-01）

詳細解析JSON・過去の集計JSON・練習用中間データをgzipで保存する。圧縮後に展開したバイト列が元ファイルと完全一致することを確認してから元の非圧縮ファイルを取り除く。研究データの数値を丸める処理はない。旧HTML保存版は .html.gz として同様に保持している。

src/storage.mjs により各処理は従来の .json パスで圧縮版を読める。再生成した非圧縮ファイルがある場合はそちらを優先する。現在の表や練習データを含め、ファイル名に .gz が付いたことは欠損を意味しない。

サーバーはブラウザーへgzipで配信し、ブラウザーが自動展開する。詳細表示用のデータでは、未表示の解析用フィールドを省略する。元の全結果はdata/results/*.json.gzに保持。HARD保存版は従来と同じ4本のゲージ推移・5件の運指例を含み、表示用JSONを圧縮して内蔵する。練習保存版も全4,114譜面・負荷グラフ・混フレ区間を圧縮内蔵する。

保存版の閲覧にはDecompressionStreamを備えた現在のChrome/Edge/Firefox等を使う。依存ファイルを取りに行かず、HTML内のデータを展開する仕組み。Node.js側では標準zlibを使用し、追加パッケージは不要。

## 更新手順

解析や練習データを再生成した後、`npm run compact` で圧縮し、`npm run export` と `node scripts/export-practice.mjs` で保存版を更新する。`npm run verify:offline` でHARD保存版の件数・モデル・固定必要能力・構文を照合できる。

`npm run package:github` はartifacts/DP-HARD-LAB-GitHub.zipを作る。ソース・現在のサイト・現在の保存版・圧縮済み詳細結果・参照統計を含む。Git履歴、node_modules、元譜面キャッシュ、計算途中のstagingは含まない。旧HTML版はローカルに圧縮保存し、この現在版パッケージには含めない。ZIPを展開しGitHub Desktopやgitで保存する用途。ZIPそのものをGitHubのファイル画面へアップロードする用途ではない。

元譜面は従来からGit対象外。別PCで再シミュレーションする場合は `npm install` と `npm run restore` で元譜面を復元する。練習集を再集計する場合は `node scripts/collect-practice.mjs` も必要。保存済みの表・保存版閲覧には譜面の再取得は不要。

## 既存Git履歴について

軽量化前の作業ツリーはGit対象の実ファイル合計約1.60GB。詳細結果だけで996.8MB、HARD保存版129.9MB、練習保存版33.0MBだった。新HARD保存版27.9MB、新練習保存版8.4MB。旧ファイル・解析データ6,763件の可逆圧縮で約1.078GBを削減した。

未送信コミット53ffe89には、129,907,723バイトの旧HARD保存版blobが含まれていた。2026-10-01にユーザーの承認を得て、この1コミットを軽量版に差し替えた。mainの親コミットは既存origin/mainのad1fbc9を維持し、送信対象の履歴に100MiB超のファイルがないことを確認した。通常のmainのpushで保存できる。

元のコミットはローカルの控えブランチ `codex/backup-before-compaction-20261001` に保持。このブランチには旧巨大ファイルが含まれるため、GitHubへの送信対象はmainだけとし、全ブランチ一括pushは行わない。旧状態を参照するには `git show codex/backup-before-compaction-20261001:<ファイル名>` を使える。

既存 .git の約1.9GiBはこのファイル圧縮では縮まらない。履歴・Gitオブジェクトの整理は別の作業であり、過去データの回復可能性を考慮して実施する必要がある。
