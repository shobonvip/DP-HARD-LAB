# DP 練習譜面集

正規譜面から反復機会を探す試作版。HARD難度ランキングとは別の指標で、練習による上達量を測ったものではない。

## 対象と再現

既存の☆5～9 ANOTHER・☆10～12全譜面に、☆7～9 NORMAL/HYPERを追加。TexTageの既存テーブルとHTMLキャッシュから1,493譜面を復元し、ノーツ数を検証した。今回は追加のネットワーク取得は不要だった。候補4,210譜面中4,114譜面を解析、96譜面はソース未提供等で推薦から除外。最新収録状況への追従を保証するものではなく、既存テーブルのスナップショットに基づく。

`node scripts/collect-practice.mjs` → `node scripts/build-practice.mjs` → `node scripts/export-practice.mjs`。

練習用カタログはdata/practice/catalog.json。HARD表のカタログ・難度換算母集団は変更していない。低難度の追加譜面は配置と人間動作負荷を集計した段階で、H5全オプション試行は未実施。

## 選び方

体力・テクニックは下記のシミュレーション負荷で推薦。それ以外は指定テーマが3回以上・2小節以上出現する譜面を表示し、出現回数/分と出現小節の広がりを加点、負荷の突出度を減点する。同じテーマ・同程度の公式難度内で候補を探す指標であり、異なるテーマ間の点数は比較しない。回数は両手合計、左右別も表示する。

- 旧体力・テクニックの検出回数は比較用データとして保持しているが、practice-5以降の推薦順や表示には使わない。
- 皿：皿動作回数。BSS端点を含む。着地は直前の同じ手の動作が皿で、0.6秒以内の鍵盤復帰。
- 同時押し：片手3鍵以上の新規打鍵。保持中の鍵は加算しない。
- 小階段/大階段：単鍵・皿なしで、同じ方向へ隣接鍵が3～5個/6～7個続く列。打鍵間隔40～650ms。方向転換・同時押し・長い休符で区切る。リズムが均等であることは必須にしない。同色階段は鍵間隔2の列を別集計する。
- 縦連/トリル：40～300msでの単鍵再打鍵または単鍵A-B-A。CN複合：鍵盤CN保持中の鍵盤動作。

## 体力・テクニックの動作シミュレーション（practice-5）

皿イベントとBSSを取り除き、鍵盤CNを保った正規譜面をhumanFeaturesで再計算する。実譜面の皿への移動・皿疲労・着地を含まない仮想条件。HARDゲージの生存率ではなく、既存人間動作モデルの負荷時系列を使う。

左右別の2秒区間ごとに、身体負荷と技術負荷（cognitive＋指移動×1.3/左右能力係数）の動作平均を求め、動作頻度/秒が3未満なら頻度/3を掛ける。無打鍵区間も0として含める。技術負荷には認識・拡張・配置切替が含まれる。曲の代表値は各区間で負荷の高い手を採用し、平均と95百分位を表示。グラフは左右個別、縦軸は曲ごとに調整するため高さだけで曲間比較しない。

- 体力：身体負荷75百分位×0.65をその曲内の持続基準とする。基準以上の秒数・最長連続秒数・基準30%未満の低負荷秒数を算出。平均負荷×基準以上の時間割合×√(最長連続秒数/曲長)÷√(95百分位/平均、最低1)で推薦。
- テクニック：平均技術負荷×(95百分位の半分以上の区間割合)÷√(95百分位/平均、最低1)で推薦。極端な一瞬だけの難所は順位が上がりにくい。

閾値や頻度補正は研究上の仮定。持続秒数は疲労限界やプレイヤー個人の体力を表さない。認識・指移動・切替・拡張の内訳は動作単位の未正規化平均で、グラフの平均とは分母が異なり単純加算はできない。2秒内の短い休符や負荷変動も平滑化される。

## 指定運指の条件

右手基準の親3は左手では親5、親5は左手では親3、中5・6は左手では中3・2。内部座標を左右対称化して集計し、画面の確認箇所では実際の鍵番号へ戻す。

自動運指モデルはホームポジションを強く選ぶため、指定運指の練習は別条件で抽出する。これはその運指が必須・最適であるという判定ではない。

- 親3：3鍵を押す場面で2鍵を同時に押す、または直前の単鍵2から80～450msで移る。1鍵の新規打鍵/保持と皿がない。
- 親5：5鍵を押す場面で3鍵を同時に押す、または直前の単鍵3から80～450msで移る。1鍵の新規打鍵/保持と皿がない。
- 中5・6：56同時押し、または5と6の80～450msの移行。4鍵の新規打鍵/保持と皿がない。56同時押しは中5・薬6を試す候補で、同じ中指で2鍵同時に押す指示ではない。

いずれも4鍵以下。指の個体差、手首の姿勢、全ての前後関係まで保証しない。痛みや強い伸ばしが必要な配置を指定運指に合わせる必要はない。正規を基準とし、FLIP＋両MIRRORなら左右の手に対する相対配置を保って交換できる。RANDOM/MIRROR単独では練習対象が変わるため、この一覧の集計は適用しない。

推薦の妥当性を実プレイで確認した厳選リストではなく、譜面内容に根拠のある候補集。

## 左右独立・混フレ（practice-4）

重複しない2小節区間ごとに、皿を伴わない鍵盤動作を左右別に集計する。両手各4動作以上、各手の動作が区間内の打鍵時間幅の65%以上を占め、左右の活動時間が60%以上重なることを条件にする。片手ずつ交代するだけの配置を除くための条件である。

左右15ms以内を同時打鍵とみなし、非一致率が20%以上、左右の打鍵間隔の分布差が15%以上の区間を採用。分布差は各手の打鍵間隔の0/25/50/75/100百分位を比較し、差を大きい方の間隔で割った平均。同じリズムのユニゾンと、等間隔をずらしただけの左右交互打鍵を除外する。

表示回数は検出区間内の鍵盤動作数で、混フレのフレーズ数ではない。別途区間数・開始終了秒・左右の動作数を表示。曲名による加点はしない。音楽的な声部や旋律を聞き分ける機能ではなく、同じ間隔分布でも並びだけ違う混フレや、短い混フレは取りこぼしうる。

確認例：Wanna Party? ANOTHER ☆9は12区間・24小節、左148/右182の計330動作。7.50～11.02秒、18.75～22.27秒、22.50～26.02秒などを検出。既存HARDシミュレーションとその他の練習分類の計算式は変更していない。
