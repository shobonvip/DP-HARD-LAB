## 検証

全742譜面の順位相関 0.75 → 0.80、平均絶対順位差 15.38 → 13.49。非ソフラン659譜面の相関 0.75 → 0.81、平均絶対順位差 15.13 → 13.00。

係数選定は学習群の誤差のみ。曲名で分割した保留群は選定後に確認。過去にもereterで調整した母集団であり、独立した実プレイ検証ではない。CNの架空の再打鍵を除く修正を含むため、全体差は係数変更だけの効果ではない。

## 配置難が低く出た理由

- 手全体の動作頻度、指頻度、片手バースト、高速連続動作が共通する時間制約を重複計上していた。共有分を限定して減らし、縦連の専用負荷・実移動・指の回復時間は保つ。
- 単独ではホーム運指で取れる鍵でも、複数鍵の形が変わると運指を準備し直す必要がある。混色同時押しへの切り替え、同じ鍵の担当指変更、指の衝突を直前配置と時間間隔から評価する。同形反復とA-B-Aは準備負荷を軽減する。
- GOBBLEやDXY!などは無理皿を早押し・遅押しへ配分する計画が実戦より有利な可能性もある。この修正だけで全ての過小評価を説明しない。
- CN/HCN、ソフラン、疲労、実際のRANDOM当たり分布などは別要因。ソフランは係数選定から除外した。BAD後に意図的に一拍休む戦略は未実装。

## 補正を一つずつ外した比較

新モデルの推奨配置を固定してH5必要能力を再探索。基準はCN修正済みで、旧モデルの最良配置とは異なる場合がある。全8曲で「両方」の値が本番H5と一致することを確認した。

| 譜面 | 基準 | 重複軽減のみ | 配置追加のみ | 両方 |
|---|---:|---:|---:|---:|
| Logic Board | 4.59 | 3.72 | 5.83 | 4.96 |
| GOBBLE | 4.71 | 3.72 | 5.83 | 4.96 |
| DXY! | 5.33 | 4.34 | 6.08 | 5.09 |
| CoMAAAAAAA | 5.21 | 4.34 | 6.95 | 5.96 |
| TITANS RETURN | 4.47 | 3.60 | 5.33 | 4.34 |
| 灼熱 Pt.2 Long Train Running | 4.71 | 3.60 | 5.09 | 3.85 |
| 覚悟せよ！エンタンメ～ン ～より身の切り売り自暴自棄版～ | 6.33 | 4.59 | 6.70 | 4.96 |
| 打打打打打打打打打打 | 5.71 | 4.22 | 5.96 | 4.34 |

- **CoMAAAAAAA**：配置切り替えの追加で必要能力が5.21→6.95。両方適用後でも5.96となる。混色同時押しの切り替えを十分に数えていなかったという仮説と整合する。ereterとの差は−52.56→−19.37ポイント。
- **Logic Board / GOBBLE**：配置追加は難化方向に作用し、全体順位も改善。ただし差は依然−51.15 / −60.46ポイント。直前一動作の準備負荷だけでは足りず、複雑な運指の連続や皿への移行、ずらし入力の成功を過度に楽観している可能性がある。正規の指標だけでは推奨配置での原因を断定できない。
- **DXY!**：配置追加による難化より共有負荷の軽減が大きく、差は−52.36→−56.75へ悪化。無理皿・連打・鍵盤の組合せと、早押し・遅押し計画の実行失敗は引き続き不足候補。今回の修正で解決したとは扱わない。
- **TITANS RETURN LEGGENDARIA**：CN拘束の強い譜面で、差は−73.01→−75.71。CN保持指の架空の連打を削除する正当な修正は、欠けているCN/HCN固有の難しさの代替にはならない。拘束中の担当指の維持やHCN継続判定の精査が必要。
- **灼熱Pt.2**：配置追加が小さい一方、頻度の共有分が大きく減るため、差は−58.77→−74.70へ悪化。今回の軽減は皿の動作頻度にも作用する。複雑な連皿の認識・押し引き失敗を補うモデルは不足しており、総合改善だけを根拠にこの曲の改善とはしない。
- **エンタンメ～ン / 打打打**：配置追加は小さく、共有負荷の軽減が主に作用。単発5%☆は12.4→11.8 / 12.0→11.5。☆11には今回のereter照合データがないため、改善の実証ではなく変更方向の確認。

## 残る群の偏り

旧版の高速連続動作上位25%の偏りは+9.32→+6.94、片手集中は+7.03→+6.17、縦連は+3.00→+1.42ポイント。新しい配置切り替え負荷上位25%は−7.86→−0.78まで改善した一方、旧版の拡張運指負荷上位25%は−7.56→−8.25で悪化した。配置難のすべてを解消したわけではない。
